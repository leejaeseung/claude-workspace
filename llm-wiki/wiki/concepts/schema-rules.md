# Schema 규칙 작성법

> 관련 페이지: [[llm-wiki-methodology]]
> 최초 작성: 2026-04-21

---

## 개념

Schema는 LLM을 "챗봇"에서 "위키 관리자"로 전환시키는 규칙 파일이다.
`CLAUDE.md` 또는 `AGENTS.md` 파일로 작성한다.

---

## 기본 Schema 예시

```markdown
# Wiki 운영 규칙

## 공식 문서 참조 원칙 (필수)
- 모든 wiki 페이지는 반드시 공식 문서를 1차 출처로 참조
- 블로그/튜토리얼은 보조 자료로만 사용 — 단독 출처 금지
- 공식 문서 URL과 버전 정보를 메타데이터에 명시
- 공식 문서가 없는 내용은 ⚠️ 비공식 출처 블록으로 표시

## 새 자료 입력 시
- 공식 문서 URL 확인 후 우선 수집
- raw/ 폴더에 원본 저장 (수정 금지)
- wiki/ 에 요약 페이지 작성
- 관련 기존 위키 페이지에 링크 추가
- index.md 갱신
- log.md에 처리 기록

## 질문 처리 시
- 가치 있는 질문 결과는 새 wiki 페이지로 저장
- 기존 페이지가 있으면 내용 갱신

## 충돌 처리
- 상충하는 주장은 명시적으로 표시
- 출처를 함께 기록

## 연결 원칙
- 관련 개념은 [[wikilink]] 형식으로 연결
- 고아 페이지 최소화
```

---

## 설계 원칙

1. **공식 문서 우선**: 신뢰할 수 있는 1차 출처 확보
2. **명확성**: AI가 모호하게 해석할 여지를 줄임
3. **우선순위**: 어떤 작업을 먼저 할지 명시
4. **경계**: raw는 읽기 전용, wiki는 쓰기 가능
5. **연결**: 문서 간 링크 규칙 정의
