# Forge 작업 규칙

Hetzner 서버에서 AI 에이전트가 모바일 앱 프로젝트를 관리하고, Android 앱으로 원격 명령을 내리는 개인 프로젝트.

## 시작 전 필수

1. **`forge/docs/PLAN.md`를 먼저 읽는다.** 결정 사항, 아키텍처, 작업 목록(T번호), 상태가 모두 여기에 있다.
2. 작업은 `feature/forge` 브랜치에서 한다.
3. 요청이 T번호를 가리키면 PLAN.md의 해당 상세와 완료 기준을 따른다.

## 작업 후 필수

- PLAN.md **5장 상태표**와 **7장 진행 기록**을 갱신한다.
- 결정이 바뀌었으면 PLAN.md 2장을 먼저 고친다(바뀐 이유도 기록).
- 사람이 해야 할 단계가 생기면 `forge/docs/plan.html` 체크리스트에도 반영한다(명령어 포함). 바탕 화면 사본(`C:\Users\wasd2\OneDrive\바탕 화면\forge-plan.html`)도 같은 내용으로 덮어쓴다.

## 지켜야 할 제약

- **비용 최소화가 최우선이다.** 월 총 1.4만~2만원(서버 + API). 새 유료 서비스를 도입하려면 먼저 사용자에게 묻는다.
- 서버 RAM은 4GB다. Docker, 로컬 Android 빌드, 상시 실행 프로세스를 추가하기 전에 메모리 영향을 따진다.
- API 모드의 기본 모델은 `claude-haiku-5-5`, 고급 모델은 `claude-sonnet-5-5`. 이 결정은 사용자가 비용 때문에 내린 것이다.
- 공개 포트를 새로 열지 않는다. 모든 서비스는 Tailscale 내부에서만 접근한다.
- 비밀값(API 키, PAT, Bearer 토큰)을 커밋하지 않는다. 서버의 `.env`만 사용한다.
- 사람이 실행할 명령은 WSL 기준으로 복사해서 바로 붙여넣을 수 있게 쓴다.
