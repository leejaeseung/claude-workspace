6. 문제 해결

증상원인과 해결
Hetzner에서 CX23이 품절다른 Location(Nuremberg, Helsinki)도 확인합니다. 그래도 없으면 CAX11(ARM, 2 vCPU/4GB)을 써도 됩니다. 로컬 Android 빌드를 하지 않으므로 ARM이어도 문제없습니다.
스크립트가 "authorized_keys가 비어 있습니다"로 중단서버를 만들 때 SSH 키를 등록하지 않은 경우입니다. Hetzner 콘솔 → 서버 → Rebuild로 Ubuntu 24.04를 다시 설치할 때 SSH 키를 지정합니다. 또는 서버를 삭제하고 새로 만듭니다.
스크립트가 중간에 실패오류 메시지를 확인한 뒤 같은 명령으로 다시 실행하면 됩니다. 여러 번 실행해도 안전하게 만들었습니다. 원인을 모르겠으면 오류 출력을 Claude에게 붙여넣으세요.
tailscale up에서 멈춘 것 같음로그인 URL 승인을 기다리는 중입니다. URL이 화면 위로 지나갔다면 다른 터미널에서 ssh root@<공인IP> 'tailscale up --ssh --hostname=forge'를 실행해 URL을 다시 받습니다. 승인 후 스크립트를 다시 실행합니다.
ssh admin@... 접속 실패root 세션이 아직 열려 있다면 그 세션에서 ls -l /home/admin/.ssh/로 키 파일을 확인합니다. 이미 닫혔다면 Hetzner 콘솔 → 서버 → Rescue → Reset root password로 비밀번호를 받은 뒤, 콘솔(>_ 아이콘) 웹 터미널로 접속해 복구합니다.
ntfy 알림이 휴대폰에 안 옴① 휴대폰 Tailscale이 켜져 있는지 확인 ② Android 설정 → 앱 → ntfy와 Tailscale → 배터리 → 제한 없음 ③ 서버에서 systemctl status ntfy 확인 ④ 휴대폰 브라우저로 http://<Tailscale IP>:2586이 열리는지 확인
Expo Go에서 접속이 안 됨① REACT_NATIVE_PACKAGER_HOSTNAME을 Tailscale IP로 지정했는지 확인 ② 휴대폰 브라우저로 http://<Tailscale IP>:8081/status를 열었을 때 packager-status:running이 나오는지 확인
Expo Go가 "SDK 버전이 맞지 않음" 표시Play 스토어에서 Expo Go를 최신으로 업데이트합니다. 그래도 안 되면 프로젝트 폴더에서 npx expo install --fix를 실행하거나, Expo Go가 지원하는 SDK로 맞춰 달라고 Claude에게 요청합니다.
forge 계정에서 git push 인증 실패sudo -iu forge → gh auth status로 로그인 상태 확인 → gh auth setup-git 실행. 토큰이 만료됐다면 STEP 1에서 새로 발급한 뒤 gh auth login을 다시 합니다.
repo 생성 권한 오류 (403)토큰의 Resource owner가 조직인지, Administration 권한이 Read and write인지 확인합니다. 조직 설정에서 토큰 승인이 대기 중인지도 확인합니다.
서버가 느림, 메모리 부족free -h로 확인합니다. Metro는 한 번에 하나만 띄웁니다(pkill -f "expo start"로 정리). 그래도 부족하면 Hetzner에서 서버 타입을 한 단계 올립니다(Rescale, 디스크 유지 옵션).
새 Claude 세션이 계획을 모름claude-workspace 폴더에서 Claude를 실행했는지, feature/forge 브랜치인지 확인합니다. 요청할 때 forge/docs/PLAN.md 경로를 꼭 포함하세요.

7. 운영 원칙

원칙내용
공개 포트 0개모든 접근은 Tailscale 내부망으로만 합니다. 앱 공유가 필요하면 상대방을 tailnet에 초대합니다.
main 보호에이전트는 forge/<task-id> 브랜치에서만 작업합니다. 머지는 앱에서 승인한 뒤에만 합니다.
배포APK는 최초 1회와 네이티브 모듈 변경 시에만 빌드합니다. 그 외에는 eas update로 OTA 배포합니다.
앱 데이터기기 로컬 저장이 우선입니다. 두 사람이 공유해야 할 때만 같은 서버에 Hono + SQLite를 둡니다.
비밀값서버 .env에만 둡니다. GitHub는 Forge 전용 fine-grained PAT를 씁니다. 에이전트 작업 디렉터리에는 비밀값을 두지 않습니다.
구독 모드 주의사용량 한도를 개인 사용과 공유합니다. 현재 약관을 확인하세요. 한도가 충돌하면 API 모드로 전환합니다.
