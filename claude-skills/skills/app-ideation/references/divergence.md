# 발산 기법

매 실행마다 서로 다른 기법을 3개 이상 고른다. 최근 기획서에서 쓴 기법은 가급적 피한다.

1. **하루 마찰 일기** — 특정 인물(예: 맞벌이 부모, 자취 대학생, 70대 노인, 야간 근무자, 반려동물 보호자, 외국인 거주자)의 하루를 시간대별로 따라가며 사소하게 짜증나는 순간 10개를 적고, 그중 앱으로 줄일 수 있는 것을 고른다.
2. **센서 × 상황 조합** — 모바일 기능(GPS, 가속도계, 기압계, 카메라, 마이크, NFC, 블루투스, 걸음 수, 화면 사용시간, 알림, 위젯, 잠금화면, 캘린더, 사진첩) 하나와 생활 상황(출퇴근, 장보기, 이사, 병원, 육아, 여행, 운동, 요리, 수면, 경조사) 하나를 무작위로 짝지어 본다.
3. **오프라인 행동 디지털화** — 사람들이 아직 종이, 기억, 단톡방, 엑셀로 하고 있는 일(예: 공동 비용 정산 외의 것, 집안 소모품 교체 주기, 약 재고, 경조사비 기록)을 찾는다.
4. **역발상** — 기존 앱 카테고리의 전제를 뒤집는다 (예: "더 많이 쓰게 하는 앱" → "덜 쓰게 하는 앱", "개인용" → "두 사람이 함께 쓰는 앱", "기록" → "잊어버리게 해주는 앱").
5. **제약 강제** — 극단적 제약을 건다: 화면 없이(소리/진동만), 하루 10초만 사용, 입력 없이 자동으로, 오프라인 전용, 버튼 1개.
6. **이웃 분야 이식** — 한 분야의 검증된 메커니즘을 다른 분야로 옮긴다 (예: 게임의 스트릭 → 가족 안부, 물류의 추적번호 → 빌려준 물건).
7. **한국 생활 특화** — 한국 고유의 생활 맥락(분리수거 요일, 관리비, 전세/월세, 택배 공동현관, 지역화폐, 경조사 문화, 학원 픽업)에서 문제를 찾는다.
8. **최근 변화** — 최근 1~2년의 기술/제도/생활 변화(온디바이스 AI, 새 OS API, 법·제도 변경, 고령화, 1인 가구 증가)가 새로 가능하게 만든 것을 찾는다. 웹 검색으로 최신 동향을 확인해도 된다.

## 좋은 후보의 신호
- 문제를 겪는 순간이 구체적이다 ("월요일 아침 분리수거장 앞에서")
- 사용 빈도가 주 1회 이상이거나, 드물지만 겪을 때 고통이 크다
- 첫 사용까지의 설정이 1분 이내로 상상된다
- 한 문장으로 설명했을 때 "아 그거 필요했어"라는 반응이 상상된다
