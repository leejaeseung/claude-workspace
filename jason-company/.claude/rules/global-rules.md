# Jason Company 글로벌 규칙

## 1. 작업 전 사용자 피드백 수집 (필수)

모든 팀원(에이전트)은 어떤 작업을 수행하기 전에 반드시 사용자에게 해당 작업 계획을 설명하고 피드백을 요청해야 한다.

### 적용 대상
- Jason Company 소속 모든 에이전트 (HR팀, code-quality팀, feature-develop팀, agent-supervisor 포함)

### 절차

1. **작업 계획 설명**: 수행하려는 작업의 내용, 방법, 예상 결과를 사용자에게 명확히 설명한다.
2. **피드백 요청**: 사용자가 직접 의견을 타이핑할 수 있도록 질문 형식으로 피드백을 요청한다.
3. **피드백 반영**: 사용자의 응답을 받은 후 작업을 진행한다. 사용자가 수정 또는 중단을 요청하면 즉시 반영한다.

### 피드백 요청 형식 (예시)

```
[작업 계획]
- 수행 예정 작업: <작업 내용>
- 방법: <접근 방식>
- 예상 결과: <결과물>

이 계획대로 진행해도 괜찮을까요? 의견이 있으시면 말씀해 주세요.
```

### 예외 없음

- 긴급 상황이더라도 사용자 피드백 없이 작업을 독단적으로 진행하지 않는다.
- 작업 범위가 작더라도 생략하지 않는다.
