# Code Quality 팀 KPI

> 버전: v2 | 확정일: 2026-05-05

## 팀 리더 — 김도현

- KPI 1: ARB 의사결정 기준 준수율 분기별 95% 이상, 모든 결정의 정량 근거(월 호출수/Financial Impact/SLA) 문서화 100%
- KPI 2: PR당 critical 주석 평균 3개 이내, 주석당 30글자 이내 (3-30 Rule 준수율 90% 이상)
- KPI 3: **Context 관리 표준화** — 에이전트별 프롬프트 템플릿 표준화 및 분기별 토큰 사용량 25% 절감 (불필요한 컨텍스트 제거, 역할별 최소 컨텍스트 정의)
- KPI 4: **업무 지시 효율화** — SendMessage 1건당 평균 토큰 사용량 분기별 20% 감소, 중복 컨텍스트 전달 제로화
- KPI 5: 18개월 시점 시니어 2명 ARB 80% 독립 수행, 멘티 만족도 70점 이상
- KPI 6: Cyclomatic Complexity 연간 30% 감소, 빌드 시간 50% 단축
- KPI 7: **가계부 앱 ARB 리딩** — 착수 30일 이내 아키텍처 기준선(레이어 분리, 패턴 가이드, 테스트 기준) ARB 합의 수립
- KPI 8: 분기당 신기술 학습 16시간 이상 (Arrow-kt 기반 Either 도입 로드맵, 가계부 앱 시범 적용)

## 박지수 — OOP 디자인 패턴 전문가

- KPI 1: ARB 패턴 안건 분기당 4건 이상 주도, 표준 패턴 가이드 6건 작성 (가계부 앱 적용 패턴 우선)
- KPI 2: Critical Path 모듈 디자인 패턴 적용률 80% 이상, 안티패턴 리포트 분기당 2건 제출
- KPI 3: **기술 역량** — Kotlin sealed class 기반 도메인 모델링 및 Arrow-kt Either 활용 사례 분기당 3건 작성, 사내 기술 발표 1회
- KPI 4: **가계부 앱 투입 준비** — 거래/카테고리/예산 도메인 패턴 설계서 프로젝트 착수 전 완성, Spring Boot+JPA 기반 Aggregate 설계 PoC 1건 제출
- KPI 5: ARB 독립 의사결정 수행, 패턴 워크숍 분기당 1회 (참여자 만족도 80점 이상)

## 이준혁 — 리팩토링 전문가 (6개월 적응 조건)

- KPI 1: 코드 리뷰 협업 점수 75점 이상, 부정 피드백 20% 미만 (6개월 적응 평가 통과)
- KPI 2: 레거시 모듈 결합도 분기당 평균 30% 감소, 리팩토링 PR 회귀 버그 발생률 5% 미만
- KPI 3: **기술 역량** — Strangler Fig/Branch by Abstraction 실전 적용 분기당 2건, Kotlin/Spring 레거시 → 모듈러 모놀리스 전환 사례 1건 문서화
- KPI 4: **가계부 앱 투입 준비** — 리팩토링 가드레일(코드 스멜 체크리스트, 의존성 그래프 룰) 착수 14일 이내 수립
- KPI 5: 기술 부채 레이더 분기별 갱신, ARB 우선순위 안건 3건 이상 제안

## 최아린 — 테스트 엔지니어링 전문가

- KPI 1: Critical Path 테스트 커버리지 90% 이상, 전체 75% 이상, 테스트 실행 시간 분기당 20% 단축
- KPI 2: Property-based/Contract testing 분기당 신규 모듈 2건 적용, Mutation Testing 점수 70점 이상
- KPI 3: **기술 역량** — Kotest/JUnit5+Testcontainers 기반 통합 테스트 표준 수립, JPA Slice Test 가이드 작성, 분기당 1건 사내 공유
- KPI 4: **가계부 앱 투입 준비** — 거래 정합성/멱등성 테스트 시나리오 30건 이상 사전 설계, CI 파이프라인 테스트 게이트(커버리지/성능) 착수 시점 가동
- KPI 5: 팀 테스트 표준 가이드 수립 및 온보딩 교육 100% 진행, 신규 멤버 첫 PR까지 테스트 작성 자율화 7일 이내 달성
