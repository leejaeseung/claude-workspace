# HR 채용 프로세스 (hr-chief용 상세 가이드)

Jason Company의 엄격한 채용 프로세스입니다. **hr-chief + 3명 평가자(hr-evaluator-1/2/3) + 채용 대상 팀 리더**가 협력합니다.

## 📋 프로세스 개요

```
사전 준비 단계
    ↓
1차 검증 (서류 심사, 70점 이상)
    ↓
2차 검증 (실무 능력 테스트, 75점 이상)
    ↓
3차 검증 (심층 인터뷰, 80점 이상)
    ↓
최종 채용 결정 (프로젝트 레벨 에이전트 생성)
```

---

## 🔍 상세 실행 단계

### 📋 사전 준비 단계

**1단계: hr-chief가 평가 기준표 작성**

```
역할 및 요건: {지원받은 ARGUMENTS}

이 역할에 필요한 업무 범위와 필수 역량을 분석한 후, 다음을 작성해주세요:

1. **평가 기준표** (항목 / 배점 / 평가 지표) - 총 100점
2. **각 단계별 통과 점수**:
   - 1차 서류 심사 통과: 70점 이상
   - 2차 실무 능력 테스트 통과: 75점 이상
   - 3차 심층 인터뷰 채용 권장: 80점 이상

명확하고 객관적인 기준을 만들어주세요.
```

hr-chief가 제시한 **EVALUATION_CRITERIA**를 다음 단계에 사용합니다.

**2단계: hr-chief가 후보 프로필 생성**

```
위의 평가 기준표를 바탕으로, 이 역할에 지원한 AI 에이전트 후보의 프로필을 생성해주세요.

프로필 내용:
- 이름/역할명
- 자기소개 (역할 관련 경험과 역량)
- 이 역할에 지원한 이유/목표
- 보유 기술/역량
- 자신의 강점과 개선 필요 영역

현실적이고 균형잡힌 프로필을 만들어주세요.
```

hr-chief가 제시한 **CANDIDATE_PROFILE**을 다음 단계에 사용합니다.

---

## 🔍 1차 검증 — 서류 심사 단계

**3단계: 3명 평가자가 독립적으로 평가**

각 평가자에게 다음 정보를 제공하고 평가하도록 합니다.

**hr-evaluator-1 (기술역량)**:
```
역할 및 요건: {ARGUMENTS}

평가 기준표:
{EVALUATION_CRITERIA}

후보 프로필:
{CANDIDATE_PROFILE}

위 기준표에 따라 후보를 기술역량 관점에서 평가해주세요.
당신의 채점과 근거, 그리고 다음 단계 진행 의견을 제시해주세요.
```

**hr-evaluator-2 (커뮤니케이션)**:
```
[동일하게] 후보를 커뮤니케이션/팀 적합성 관점에서 평가해주세요.
```

**hr-evaluator-3 (창의성)**:
```
[동일하게] 후보를 창의성/아이디어 관점에서 평가해주세요.
```

응답: **SCORE_1, SCORE_2, SCORE_3**

**4단계: hr-chief가 1차 판정**

```
평가 기준표: {EVALUATION_CRITERIA}

1차 검증 점수:
- [기술역량 평가]: {SCORE_1}
- [커뮤니케이션 평가]: {SCORE_2}
- [창의성 평가]: {SCORE_3}

이 세 평가를 종합하여 1차 검증 통과 여부를 판정해주세요.

1차 통과 기준: 평균 70점 이상

판정 결과와 이유를 명시해주세요.
```

**결과**:
- ❌ **탈락**: 불채용 사유 제시, 프로세스 종료
- ✅ **통과**: 2차로 진행

---

## 🧪 2차 검증 — 실무 능력 테스트 단계

**5단계: hr-chief가 실무 시나리오 출제**

```
역할 및 요건: {ARGUMENTS}

1차 검증 통과: 위 후보가 1차를 통과했습니다.

2차 검증을 위해 이 역할에 맞는 **실무 시나리오 2개**를 출제해주세요.

각 시나리오는:
- 실제로 이 역할에서 마주칠 법한 구체적 상황
- 문제 해결에 기술·창의성·커뮤니케이션이 모두 필요함
- 명확한 평가 포인트 3~4개 포함

시나리오 1, 2를 제시해주세요.
```

hr-chief가 제시한 **SCENARIO_1, SCENARIO_2**를 사용합니다.

**6단계: 후보가 시나리오에 대해 상세 응답**

후보 에이전트(CANDIDATE_PROFILE)가 2개 시나리오에 대해 상세히 응답하도록 요청:

```
시나리오: {SCENARIO_1}

당신은 방금 이러한 상황에 직면했습니다. 당신의 대응 방안을 상세히 설명해주세요.
- 문제 분석
- 해결 방법론
- 실행 계획
- 리스크 관리
```

응답: **SCENARIO_RESPONSE_1, SCENARIO_RESPONSE_2**

**7단계: 3명 평가자가 실무 능력 평가**

**hr-evaluator-1**:
```
기준표: {EVALUATION_CRITERIA}

시나리오 응답:
{SCENARIO_RESPONSE_1}
{SCENARIO_RESPONSE_2}

위 응답들을 기술역량 관점에서 평가해주세요.
```

**hr-evaluator-2, hr-evaluator-3**: (동일 방식)

응답: **SCENARIO_SCORE_1, SCENARIO_SCORE_2, SCENARIO_SCORE_3**

**8단계: hr-chief가 2차 판정**

```
평가 기준: {EVALUATION_CRITERIA}

2차 검증 (실무 능력 테스트) 점수:
- [기술역량]: {SCENARIO_SCORE_1}
- [커뮤니케이션]: {SCENARIO_SCORE_2}
- [창의성]: {SCENARIO_SCORE_3}

2차 검증 통과 여부를 판정해주세요.

2차 통과 기준: 평균 75점 이상

판정 결과와 이유를 명시해주세요.
```

**결과**:
- ❌ **탈락**: 불채용 사유 제시, 프로세스 종료
- ✅ **통과**: 3차로 진행

---

## 💬 3차 검증 — 심층 인터뷰 단계

**9단계: hr-chief가 심층 인터뷰 질문 작성**

```
1차·2차 평가 요약:
- 1차 점수: {1차 종합 점수}
- 2차 점수: {2차 종합 점수}

평가 기준: {EVALUATION_CRITERIA}

3차 심층 인터뷰 단계입니다.

다음 포인트를 중심으로 인터뷰 질문 3~4개를 작성해주세요:
1. 1차·2차에서 드러난 약점 또는 개선 필요 영역에 대한 성찰
2. 이 역할에서 이루고 싶은 구체적 목표
3. 팀과의 협업에서 본인의 강점과 기여도
4. 도전적 상황에서의 대응 방식

깊이 있는 인터뷰 질문을 제시해주세요.
```

hr-chief가 제시한 **INTERVIEW_QUESTIONS**를 사용합니다.

**10단계: 후보가 인터뷰 질문에 답변**

```
질문: {INTERVIEW_QUESTION}

이 질문에 대한 당신의 생각과 경험을 상세히 설명해주세요.
```

응답: **INTERVIEW_RESPONSE_1, INTERVIEW_RESPONSE_2, ...**

**11단계: 3명 평가자가 최종 평가 및 의견 제시**

**hr-evaluator-1**:
```
기준표: {EVALUATION_CRITERIA}

인터뷰 응답:
{INTERVIEW_RESPONSE_1}
{INTERVIEW_RESPONSE_2}
...

이 후보의 심층 인터뷰 응답을 평가한 후, 채용 의견을 제시해주세요.
(채용 권장 / 신중히 검토 필요 / 부정적)

당신의 최종 점수와 근거를 명시해주세요.
```

**hr-evaluator-2, hr-evaluator-3**: (동일 방식)

응답: **FINAL_OPINION_1, FINAL_OPINION_2, FINAL_OPINION_3**

**12단계: hr-chief가 최종 채용 결정**

```
모든 평가 결과:
- 1차 점수: {1차 점수}
- 2차 점수: {2차 점수}
- 3차 점수: {3차 점수}

평가자별 최종 의견:
- [기술역량]: {FINAL_OPINION_1}
- [커뮤니케이션]: {FINAL_OPINION_2}
- [창의성]: {FINAL_OPINION_3}

최종 채용 결정을 내려주세요.
선택지: ✅ 채용 확정 / ⚠️ 조건부 채용 / ❌ 불채용

최종 판정 근거와 함께, 채용이 확정되면 새 에이전트 정의도 작성해주세요:

---
name: <팀명>-<역할>
description: "<팀명> | <역할> - 채용된 AI 에이전트"
model: [claude-opus-4-7 / claude-sonnet-4-6 / claude-haiku-4-5-20251001 중 선택]
color: [적절한 색상]
---

(이 에이전트의 역할, 성격, 업무 방식, 응답 형식 상세히 정의)
```

**결과**:
- **❌ 불채용**: 평가 요약 및 불채용 사유 제시, 프로세스 종료
- **⚠️ 조건부 채용**: 조건 명시, 조건을 포함하여 에이전트 파일 생성
- **✅ 채용 확정**: 제시한 에이전트 정의를 이용하여 파일 생성

---

## ✅ 최종 채용 처리

**13단계: 에이전트 파일 생성 (프로젝트 레벨)**

hr-chief가 제시한 에이전트 정의를 이용하여 다음 경로에 파일을 생성합니다:

```
.claude/agents/<팀명>-<역할>.md
```

**파일명 규칙**:
- 팀명: 소문자 + 하이픈 (예: code-quality, data-analytics)
- 역할명: 한글 영문 음역 (예: leader → code-quality-leader)
- 최종 형식: `.claude/agents/code-quality-leader.md`

생성 완료 후:

```
✅ 채용 완료!

새로운 팀원:
- 파일: .claude/agents/<팀명>-<역할>.md
- 모델: {선택된 모델}

이제 `/agents` 명령으로 새 에이전트를 확인할 수 있습니다.
```

## 🎯 팀 리더 평가 참여 (개선사항)

### 각 검증 단계별 역할

| 단계 | 팀 리더 평가 관점 | 평가 항목 |
|------|------------------|---------|
| **1차** | 도메인 이해도, 팀 문화 적합성 | 기술 스택 학습속도, 팀 문화 적응, 기존 과제 공감 |
| **2차** | 실무 협업 능력, 기술 의사결정 역량 | 팀과의 협업 방식, 의사결정 공감도, 실무 실행성 |
| **3차** | 리더십 철학, 멘토링 능력 | 팀원 성장 의지, 리더십 스타일, 장기 비전 |

### 최종 점수 계산

```
최종 점수 = (HR 평가 평균 + 팀 리더 평가) / 2
```

**의견 불일치 처리**:
- 5점 이상 차이 → hr-chief가 명시적으로 분석/문서화
- 팀 리더가 부정적 의견 강력히 표현 → 특별 검토 + 조건부 채용 고려

---

## ⚠️ 주의사항

- ✅ 각 단계는 **순차적으로 진행**
- ✅ 탈락 시 **명확한 사유** 제시 (투명성 유지)
- ✅ 평가자 점수 편차 크면 그 이유를 hr-chief가 설명
- ✅ 조건부 채용 시 조건을 명확히 에이전트 파일에 포함
- ✅ 최종 파일은 **프로젝트 레벨**에만 생성 (global 저장 금지)
