## 1. 문제
- 누가: 택배 위탁 기사(개인사업자, 근로자성 없음 → 고용주가 시간을 기록하지 않음).
- 언제: 하루 중 터미널 상차 대기·분류, 프레시백 수거, 건물 내 엘리베이터 대기 구간. 근로시간 상한 입법 논의, 산재·분쟁 때 본인 기록이 없다.
- 지금은 어떻게 해결하나: 기록 없음. 노조 실태조사는 온라인 설문. 노조 주장 수치(프레시백·분류 하루 평균 56분, 일 11.1시간)는 검증된 통계가 아님.
- 왜 지금인가: 생활물류서비스산업발전법 개정안(상한은 시행령 위임)·사회적 대화 기구 논의(2026-04 이후 멈춤), CJ대한통운의 기사 앱 심야·연속근무 제한 계획.

## 2. 해결책 (v2 수정안 반영)
### 핵심 경험 (첫 30초)
권한 2개 + '오늘 시작' 버튼. 터미널은 첫 방문 때 학습(불확실하면 1탭 확정). 퇴근 시 '오늘 총 N시간 중 배송 건수에 안 잡힌 시간 M분' 요약 한 화면에서 일괄 확인·수정(운전 중 수정 UI 잠금).
### 핵심 기능 (MVP)
1. 자동 3구간: ①터미널 체류 ②차량 이동 ③단지·도보 체류. 상차 대기/분류/프레시백/엘베 대기는 위젯·잠금화면·알림 액션 '1탭 타이머/태그'(엘베는 기압계+단지 체류 '추정' 표시 → 심사에서 '탑승 이동 감지 후 태그 제안' 수준으로 낮추라는 권고).
2. 주간 리포트: 구간별 시간, 연속 근무.
3. 증빙 PDF: 자동 기록과 수정 기록을 별도 레이어로 표시, '본인 기록·법적 증거력 보장 안 됨' 고지.
### 모바일이라서 가능한 점
위치·활동 인식, 위젯, 항상 소지, 기기 내 처리.
### 하지 않을 것
서버 업로드·계정, 노조 데이터 제휴(삭제), 소속 질문, 좌표 저장(→ 심사: 실제 설계와 모순되므로 '단기 보관 후 삭제'로 정정 필요), 수입 환산.
