### 개선 라운드에서 반영한 수정
사후 알림·위치·자동 SMS 제거(risk 개선 3), 1탭 제거 시도(user-reality는 오히려 첫 가치 0 지적), 높이 3단계 거침화, 자녀 설치·기관 배포 구조 → 평균 +0.17로 정체.

### 해소되지 않은 리스크
핵심 전제(연속 사다리 시간이 위험과 상관)의 근거 없음, 주머니 폰 자동 인식 정확도 미검증, iOS 불가, 지불 주체 없음.

## 판정 (pipeline·SKILL 규칙 인용)
- 사다리 고도 경고: 통과 기준 'KILL 0, 평균 ≥ 3.5, creativity·user-reality ≥ 3' 미충족(평균 2.17 → 2.33, user-reality 2). 유망 기준 'KILL 0, 평균 ≥ 3.0' 미충족 → 탈락 후보 목록에만 기록.
- 필지 도착 일지: '`EXISTS` → 탈락' (AgriNote 2017, Farmdok).
- 수확 금지일 카운트다운: '`EXISTS` → 탈락' (Croptracker, Hectre).
- 본 존재 확인 3개 중 통과 1개(사다리)가 있었으므로 N-6의 '통과 0개면 6개까지' 확장은 해당 없음.
